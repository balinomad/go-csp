# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.4.x   | Yes       |
| < 1.4   | No        |

The module has no third-party runtime dependencies. Security issues in the Go
standard library are addressed by raising the minimum Go version declared in
`go.mod`.

## Reporting a Vulnerability

Do not open a public issue for a security problem.

Report privately through GitHub's [private vulnerability reporting](https://github.com/balinomad/go-csp/security/advisories/new) form.

Include, where possible:

- the affected version or commit
- a description of the impact
- a minimal reproduction

## Response

- Acknowledgement within 7 business days.
- A fix or mitigation target within 90 days, coordinated with you before disclosure.
- Credit in the release notes unless you ask otherwise.
